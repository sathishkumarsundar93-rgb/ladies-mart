# Ladies Mart — Frontend MVP

Rose Pink Premium responsive frontend starter for Ladies Mart.

## Included
- Responsive desktop and mobile storefront
- Search and category filtering
- Product cards, wishlist toggles, add-to-cart interaction
- Promotional sections, benefits, footer and mobile navigation
- Next.js + TypeScript + CSS + lucide-react

## Run locally
1. Install Node.js 18.17+.
2. Extract this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

## Notes
- Frontend only: no real authentication, payment, order API, seller/admin backend or shipping integration is connected.
- Product photos are remote Unsplash images and require internet access.
- Prices and offers are sample display data; replace before launch.
